# 💳 智匯卡管家 | Card Statement Manager

> **AI 驅動的個人多卡信用卡對帳與預算智慧管家**

智匯卡管家 (Card Statement Manager) 是一款專為現代多卡族群設計的**高規格個人財務對帳與智慧分析平台**。本專案以北歐極簡北歐藍白風格打磨，搭載極致響應式（Mobile/Laptop Friendly）自適應版面，整合 **SQLite 本地高效數據庫**、**Excel 雙向數據同步**，並搭載 **AI 智慧財務助理**，能一鍵匯入多卡帳單（PDF/圖片/Excel）、自動智慧歸類消費、智慧診斷超支並給出具體省錢建議。

---

## 🌟 核心亮點功能

### 1. 🗃️ 雙引擎帳單解析與 AI 自動分類
* **多格式對應**：支援拖放上傳 Excel 帳單、PDF 檔案（支援帶密碼加密 PDF 自動解密）以及 JPG/PNG 帳單影像。
* **智慧提取與降級保護**：搭載 Gemini OCR 影像與文本資料提取核心；當系統處於**「免 API 金鑰模式」**時，自動啟用高品質本地擬真提取，實現 100% 完整的無金鑰快速體驗。
* **雙引擎自動分類**：
  * **關鍵字精準匹配**：根據自訂的「關鍵字對照表」，本地自動 100% 精準匹配歸類（如 `Uber` ➔ `交通運輸`）。
  * **AI 推薦歸類**：若無匹配，自動推薦並高亮標記分類，提供極佳的待審核（TODO）核准流暢體驗。

### 2. 📊 多維度交互式 BI 儀表板
* **消費分類占比圓餅圖**：直觀顯示購物、餐飲、休閒旅遊、交通、辦公、醫療、其他之消費比例，點選扇區可自動過濾下方明細並流暢滾動。
* **月度消費與銀行趨勢長條圖**：分析歷史趨勢與發卡銀行堆疊累計；柱狀圖上方動態展示總金額標籤。
* **全平台響應式（RWD）幾何適配**：
  * **筆電自適應**：當視區小於 `1200px`（如中小型筆電或平板）時，並排圖表自動優雅切換為「垂直堆疊單欄」，給予圖表最大呼吸空間，邊框絕不出格。
  * **行動端極致優化**：高度鎖定 `200px`，且金額大於等於一萬時，自動縮短為「`X.X萬`」格式，防止橫向文字重疊。
  * **CSS Grid 防爆防線**：為卡片加入 `min-width: 0` 防護，完美修復 Chart.js Canvas 撐大 Grid 導致出格溢出的經典 Bug。

### 3. 🧠 AI 智匯管家與消費診斷
* **智慧一秒摘要**：KPI 欄位與報告即時同步，單行限制截斷附帶 Ellipsis 省略與 Hover Tooltip 顯示，卡片絕不變形。
* **精美診斷報告**：分析各分類預算執行狀態、單筆大額非預期交易（單筆高於 NT$ 3,000）、量販外送消費習慣，給出精準且極具建設性的省錢比例與多卡集中回饋建議。

### 4. 🎛️ 高級設定與資產維護面板
* **預算按月批次配置**：可設定預設或特定月份的分類預算限額，與 AI 報告深度整合。
* **關鍵字對照表批次維護**：支援單筆新增/刪除，並支援 **一鍵批次上傳/匯入 Excel 格式對照表**，自動同步更新本地 Excel 與 SQLite 資料庫。
* **PDF 帳單密碼管理庫**：以加密庫形式記錄各發卡行 PDF 解密密碼，免除每次手動輸入密碼的痛苦。

## 🛠️ 技術棧說明

* **後端核心**：FastAPI (Python 3.9+) - 高性能非同步 Web 框架。
* **本地資料庫**：SQLite3 - 輕量、高效、免安裝的關係型資料庫。
* **Excel 整合**：Openpyxl - 實現與本地 `data/` 目錄下對照表及對帳表雙向完美同步。
* **前端骨架**：HTML5 + Vanilla CSS (純 CSS Media Queries 控制亮暗主題與 RWD)。
* **圖表渲染**：Chart.js v4 + Chart.js DataLabels Plugin (動態數據標籤)。
* **圖示系統**：Lucide Icons CDN。
* **AI 核心**：Google GenAI SDK (Gemini 1.5 Flash)。

## 🚀 快速開始

### 1. 環境需求與依賴安裝
請確認您的電腦已安裝 Python 3.9+。在專案根目錄下，開啟終端機執行依賴安裝：
```bash
pip install -r requirements.txt
```
*(若無 requirements.txt，系統依賴包含：fastapi, uvicorn, pydantic, openpyxl, pillow, pdfplumber, google-genai)*

### 2. 一鍵啟動服務
本專案在根目錄下已為您預載了 Windows 批次檔，您只需雙擊執行：
```bash
RUN.BAT
```
或者手動以命令行啟動：
```bash
python app.py
```
啟動後，系統會自動在您的預設瀏覽器中打開網頁：
👉 **http://127.0.0.1:8000**

## 🔒 隱私與安全聲明

* 本專案以**本地優先 (Local-First)** 理念設計。所有的信用卡明細數據、對照表規則、預算限額與 PDF 帳單密碼，皆安全地儲存在您本地的 SQLite 數據庫中。
* 當使用**「免 API 金鑰模式」**時，所有分析與提取均在本地瀏覽器與後端規則引擎中運行，100% 保障您的敏感信用卡隱私數據絕不外流。
